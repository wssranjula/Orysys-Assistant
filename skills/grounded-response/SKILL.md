# Grounded response

Lead with the answer supported by the available evidence. Cite factual claims with the returned
evidence IDs, retain source titles, and never cite a record that was not retrieved. Clearly label
inferences and unresolved questions. When evidence is missing or conflicting, return a partial or
insufficient-evidence answer instead of filling gaps from general knowledge.
